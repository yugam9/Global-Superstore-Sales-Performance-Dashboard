# Global Superstore Sales Performance Dashboard

![Dashboard Preview](Screenshot%202026-07-07%20212316.png)

## Project Overview
Interactive Power BI dashboard built using the Global Superstore dataset.

### KPIs
- Total Sales
- Total Profit
- Shipping Cost
- Quantity Sold
- Total Orders
- Profit Margin

### Visualizations
- Sales Trend by Year
- Top 10 Products by Sales
- Sales by Segment
- Sales by Market
- Sales by Country
- Sales by Category
- Sales by Region

### Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization
